# Cursor 에디터 단축키 설명서 - 맥북용

---

## Cursor 에디터에서만 사용할 수 있는 특별한 단축키

1. **AI에게 질문하기:** `Command(⌘) + K`
   - 궁금한 점이나 코딩 도움을 AI에게 바로 물어볼 수 있습니다.

2. **파일 빠르게 찾기:** `Command(⌘) + P`
   - 원하는 파일 이름을 입력해서 빠르게 열 수 있습니다.

3. **명령 팔레트 열기:** `Command(⌘) + Shift(⇧) + P`
   - 다양한 명령어를 검색하고 실행할 수 있습니다.

4. **최근에 닫은 파일 다시 열기:** `Command(⌘) + Shift(⇧) + T`
   - 실수로 닫은 파일을 다시 열 수 있습니다.

5. **코드 정보 보기:** `Command(⌘) + I`
   - 커서가 있는 코드에 대한 정보를 빠르게 확인할 수 있습니다.

---

## 기본 단축키

1. **저장하기:** `Command(⌘) + S`
   - 지금까지 쓴 내용을 저장할 수 있습니다.

2. **복사하기:** `Command(⌘) + C`
   - 선택한 글자를 복사할 수 있습니다.

3. **붙여넣기:** `Command(⌘) + V`
   - 복사한 글자를 원하는 곳에 붙여넣을 수 있습니다.

4. **잘라내기:** `Command(⌘) + X`
   - 선택한 글자를 잘라낼 수 있습니다(없애면서 복사).

5. **실행 취소:** `Command(⌘) + Z`
   - 방금 한 일을 되돌릴 수 있습니다.

6. **다시 실행:** `Command(⌘) + Shift(⇧) + Z`
   - 되돌린 일을 다시 할 수 있습니다.

7. **찾기:** `Command(⌘) + F`
   - 글자나 단어를 빠르게 찾을 수 있습니다.

8. **모두 선택:** `Command(⌘) + A`
   - 모든 글자를 한 번에 선택할 수 있습니다.
